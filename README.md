# JavaScript Coding Test Study

JavaScript 코딩테스트와 프론트엔드 개발자에게 필요한 기초 CS를 정리하는 학습 저장소입니다.

## Structure

```text
javascript-coding-test/
├─ STUDY_PLAN.md
├─ COURSE_INDEX.md
├─ 01-fundamentals/
├─ 02-algorithms/
├─ 03-computer-science/
├─ 04-problems/
└─ docs/
```

## Rules

- 폴더 / 파일명은 영문 소문자와 `kebab-case`를 사용합니다.
- 실제 학습 내용은 한국어로 작성합니다.
- 강의의 `Chapter`는 챕터 폴더로 관리합니다.
- 강의의 각 `Clip`은 개별 폴더로 관리합니다.
- 각 클립 폴더의 `README.md`에는 개념을 정리합니다.
- JavaScript 실습이 있는 경우 같은 폴더의 `examples.js`에 코드를 작성합니다.
