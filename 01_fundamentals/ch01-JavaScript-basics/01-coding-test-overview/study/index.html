BIG-O NOTATION

시간 복잡도

입력 크기가 증가할 때 실행 시간이 얼마나 빠르게 증가하는지 나타내는 척도입니다.

Big-O 표기법

가장 빠르게 증가하는 항만 고려하여 함수의 상한을 표현합니다. 예를 들어 3N³ + 5N² + 1,000,000은 O(N³)으로 표현합니다.

효율적
비효율적
각 복잡도 항목을 클릭하면 특징을 확인할 수 있습니다.
3N³ + 5N² + 1,000,000
↓
O(N³)

KEY POINT

낮은 복잡도가 일반적으로 더 우수합니다.

단, 실제 실행 시간은 언어, 상수항, 함수 호출, 입출력 비용 등에도 영향을 받으므로 Big-O만으로 모든 성능을 판단할 수는 없습니다.

CODE EXAMPLES

시간 복잡도 예시

Linear Time

N개의 데이터 합 계산

배열의 모든 원소를 한 번씩 확인하므로 데이터 개수 N에 비례합니다.

Time Complexity O(N)
let array = [3, 5, 1, 2, 4];
let summary = 0;

for (let i = 0; i < array.length; i++) {
  summary += array[i];
}

console.log(summary);
Quadratic Time

이중 반복문

각 원소마다 다시 전체 원소를 확인하므로 대략 N × N번 연산합니다.

Time Complexity O(N²)

모든 이중 반복문이 반드시 O(N²)은 아닙니다. 반복 범위와 내부 함수 호출 비용을 함께 확인해야 합니다. 

let array = [3, 5, 1, 2, 4];

for (let i = 0; i < array.length; i++) {
  for (let j = 0; j < array.length; j++) {
    let temp = array[i] * array[j];
    console.log(temp);
  }
}
